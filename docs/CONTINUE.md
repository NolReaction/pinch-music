# Продолжение разработки

Версия **0.5.0**, Android/iOS build 6. Рабочая upstream-ветка — `work/stereo-love`; локальные изменения передаются отдельным bundle, пока пользователь не опубликует их. `main` содержит прежний прототип.

## Музыка

- Gypsy Woman переписана: органный рифф вместо неудачной вокальной редукции, C7 без постоянного C♯, связные восьмитактовые разделы и завершающий Dm. 550 атак, 120 BPM, 3:48, `bundledRevision = 5`.
- `StudioInstruments.kt` добавляет отдельные модели электропиано, деревянной маримбы и щипковых струн. Они участвуют в Gypsy Woman, On the Floor и Stereo Love; у Levels добавлено щипковое вступление при сохранённом синтезаторном хуке.
- Полные фонограммы генерируются при сборке. В Git добавлять исходники; генерируемые мастера остаются в build-каталогах. `media/instruments` не используется текущим пакетом игры.

## Импорт

- `LeadExtraction` выделяет мелодию, `ImportedArrangement` осторожно адаптирует ритм/октавы и создаёт сопровождение, `ImportedArrangementRenderer` синтезирует локальный PCM без исходного вокала. Это не source separation.
- В `PersonalCatalog` сохраняется режим Original/Instrumental. Старые записи по умолчанию Original. Сырой разбор и оригинальный файл не перезаписываются при переключении.
- Производная фонограмма хранится как `<id>-instrumental-v1.wav`. Карта при загрузке детерминированно пересоздаётся из исходной; отсутствующий аудиокэш восстанавливается. Если алгоритм/тембры меняются, увеличивать `IMPORT_ARRANGEMENT_REVISION`, чтобы звук соответствовал карте.
- `Session` переключает карту, файл и ключ рекорда вместе. Генерация идёт вне UI-потока. Удаление очищает обе записи.

## Графика и плавность

- Каскад использует общие Android/iOS меши OpenGL ES: отдельные скруглённые клавиши, деревянные пластины, полые трубы и тонкие хромовые опоры. On the Floor и Gypsy Woman отличаются формой клавиш.
- У стеклянного шарика прозрачная оболочка и внутренние цветные ленты. Он рисуется после непрозрачной геометрии с alpha blending. Освещение, фон и материалы используют палитру комнаты.
- Android выбирает MSAA 4×, затем 2×/0× при недоступности; API35+ запрашивает высокий refresh в анимации. iOS использует 4× при поддержке и повышенную частоту CADisplayLink. Аудиочас, display timestamps и bounded mailbox сохранены. Фактические FPS требуют замера на устройстве.

## Проверка перед показом

1. Выполнить `./gradlew :arranger:test :composeApp:testDebugUnitTest :composeApp:assembleDebug` и iOS Simulator build из README.
2. На устройстве прослушать начало Gypsy Woman и переходы на1:20/2:08, сравнить On the Floor через динамик и наушники.
3. Импортировать файл с голосом: послушать новую инструментальную версию, переключиться на оригинал, перезапустить приложение, проверить обе сцены и удаление.
4. Проверить паузу, возврат из фона, быстрые последовательности Levels и нагрев на длительной игре.

Фактически выполненные проверки — в [ACCEPTANCE.md](ACCEPTANCE.md). План первых тестеров — в [LAUNCH.md](LAUNCH.md).
