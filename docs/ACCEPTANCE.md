# Проверка версии 0.2.0

Проверено 14 ноября 2026 года. Тесты и сборку debug APK запускали на Linux с JDK 17. Приложение установили на эмулятор Android 7.0 (API 24, x86, экран 360×640).

## Результаты

| Проверка | Результат |
| --- | --- |
| Сборка Android | Прошли задачи `:composeApp:testDebugUnitTest` и `:composeApp:assembleDebug`. У APK версии 0.2.0 подтверждены подпись v2, минимальный API 24 и побайтовое совпадение всех 33 WAV-сэмплов инструментов с исходными файлами. |
| Автоматические тесты | 29 тестов прошли без ошибок и пропусков. Среди них выбор ближайшей ноты, границы окна попадания, очки за касание, пауза, перезапуск и сохранение собственного разбора. |
| Темп и траектория | Тесты проверяют все восемь встроенных партий, интервалы между нотами и касание шариком верхней грани платформы в момент ноты. |
| Разбор звука | На синтетической фразе анализатор вернул восемь заданных MIDI-высот, включая повтор одной ноты. На тишине и одиночных щелчках он сообщил, что подходящей мелодии нет. |
| Меню и прослушивание на Android | В каталоге выбрали Gypsy Woman, тембр маримбы и включили «Послушать». На экране двигались шарик и платформы, таймер дошёл до конца фразы, приложение вернулось в меню. |
| Раунд на Android | В On the Floor приложение вернулось из фона на паузе на 0:09. После «Продолжить» попытка завершилась с одним «Идеально», 11 пропусками и результатом 8 333 очка. После «Ещё раз» раунд без касаний дал 0 очков и 12 пропусков. |
| Декодирование на Android | Декодер из установленного APK прочитал одну тестовую фразу из WAV и MP3 на API 24. Каждый файл дал 132 300 моносэмплов. Анализатор вернул все 12 заданных MIDI-нот в исходном порядке для обоих форматов. |
| Сборка для iOS | На macOS 15 с Xcode 26.0.1 команда `xcodebuild` собрала и слинковала `PinchMusic.app` для arm64-симулятора iOS. В собранном приложении найдены WAV-сэмплы ноты до для всех трёх инструментов. Установка на физический iPhone остаётся ручной проверкой. [Журнал GitHub Actions](https://github.com/NolReaction/pinch-music/actions/runs/43628036845) |

## Повторить на телефоне

1. Выбери знакомую мелодию и «Послушать». Сравни фортепиано, маримбу и синтезатор на одной фразе.
2. В режиме «Спокойно» нажимай при касании шариком платформы. Пропусти одно приземление, затем попади в следующее. Проверь звук, отметку попадания, счёт и комбо. Повтори в режиме «В ритме».
3. Сверни приложение посреди прыжка. Вернись, нажми «Продолжить» и заверши раунд. Проверь результат и повторный запуск через «Ещё раз».
4. Выбери собственную запись с хорошо слышимой мелодией. Сравни результат через «Послушать» с исходным фрагментом. Перезапусти приложение и проверь, что доступны та же партия и кнопка «Вернуть встроенную».
5. Оцени совпадение звука с касанием отдельно через динамик и наушники. Задержку физического нажатия до звука на эмуляторе не измеряли.
